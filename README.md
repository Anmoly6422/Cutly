# Cutly — URL Shortener

A simple, fast, and modern URL shortener built with **Next.js, Node.js, Express, and MongoDB**.

Cutly converts long and difficult-to-share URLs into short, clean links that are easy to copy and share.

🔗 **Live Demo:** https://usecutly.vercel.app/

---

## ✨ Features

- 🔗 Shorten long URLs instantly
- ⚡ Fast API powered by Node.js and Express
- 🎯 Unique short codes for every URL
- 📋 One-click copy for shortened URLs
- 🔄 Automatic redirection to the original URL
- 📱 Fully responsive UI
- 🛡️ URL validation
- 🚀 Production-ready frontend and backend
- 🌐 REST API architecture
